# Подготовка Friend View 1.4.0

Ветка `codex/demo-1.4.0`, релиз 1.4.0. Полный прогон, стресс и восемь нативных запусков выполнены на одной DLL. Описание Workshop и шесть скриншотов настроек обновлены в исходниках. Проверки и ограничения: [RELEASE_1.4.0.md](RELEASE_1.4.0.md). Существующий ID Workshop сохраняется.

## Публикация 1.4.0

Исходники отправлены через Git Bash в `main` и `codex/demo-1.4.0`. Тег `v1.4.0` закреплён за коммитом `59da78d`. [GitHub Release 1.4.0](https://github.com/TselAnton/SlayTheSpire2TogetherMod/releases/tag/v1.4.0) опубликован 2026-10-16 в 06:32:08 UTC. Загружены оба идентичных имени архива мода, архив проверки с 133 PNG и SHA256SUMS. Размеры и серверные SHA-256 всех четырёх файлов совпали с локальными. Рабочая копия основной ветки в другом каталоге не переключалась.

Существующий [предмет Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3819332749) обновлён официальным ModUploader под аккаунтом TseL. Steam API подтвердил публичную видимость, шесть изображений и точное совпадение опубликованного описания с workshop.json. Последнее обновление описания: 2026-10-16T06:24:23+00:00. Сохранены ID и подписки. Каждая настройка описана с поведением On/Off и отдельным скриншотом.

Страница проверена в браузере без входа: все пять inline-изображений загрузились (637 px), описание совпадает с опубликованным. Для inline-ссылок использованы параметры преобразования изображений из штатной галереи Steam: ссылки без параметров возвращали пустое изображение. Первоначальные PNG остаются в галерее и Git. После подтверждения релиза архивы и тег не изменялись.

По отдельному запросу обложка заменена исходным кадром боя `lab-140-regent-demo.png` из проверки 1.4.0. Тот же кадр стоит первым в галерее (`00-combat.png`) и сразу после вводного абзаца. Пять иллюстраций настроек сохранены; общий экран настроек перенесён в конец (`06-defaults.png`). Изменены только изображения и описание Workshop, файлы мода не загружались повторно.

В пакет отправлена DLL с SHA-256 `5E928D2AD93B72E2B55C6B4644946B88DB03B2385D5569C5F70940E210DAA54F`, использованная полным игровым, стрессовым и нативным startup-прогонами. Сборочные метаданные могут изменить хеш при пересборке после коммита; режим CandidateDll сохраняет проверенную DLL без пересборки.

Архивы фиксируют состояние проверок перед публикацией GitHub. Логи в публичном архиве обезличены; исходные PNG не изменены.

# Публикация Friend View 1.3.1

Исходники опубликованы в `main` и `codex/demo-1.3.1`; тег `v1.3.1` закреплён за проверенным коммитом `735a57e`. [GitHub Release 1.3.1](https://github.com/TselAnton/SlayTheSpire2TogetherMod/releases/tag/v1.3.1) опубликован 2026-10-14 в 16:32:37 UTC. Загружены архив мода, его идентичный алиас Sts2Demo, архив визуальной проверки и SHA256SUMS. Серверные SHA-256 всех четырёх файлов совпали с локальными.

После GitHub обновлён существующий [предмет Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3819332749). Официальный ModUploader вошёл как TseL и подтвердил успешную загрузку; Steam API подтвердил публичную видимость и время обновления 2026-10-14 16:34:02 UTC. Публичная история изменений содержит запись 1.3.1. ID предмета и подписки сохранены. Первая попытка из другого активного аккаунта завершилась отказом; успешная загрузка выполнена после переключения владельцем аккаунта.

Бинарные файлы и опубликованные архивы не пересобирались после проверки. Отчёты внутри архивов фиксируют состояние до публикации. Полный отчёт и ограничения — [RELEASE_1.3.1.md](RELEASE_1.3.1.md).

`scripts/Prepare-Workshop.ps1` собирает четыре файла: собственную Sts2Demo.dll, Sts2Demo.json, README.md и LICENSE. `scripts/Test-PreRelease.ps1` сверяет версии и хеши ZIP/Workshop, проверяет allowlist и запускает `universal-modder publish check`.

Игровые библиотеки, извлечённые ресурсы, тестовый мод, профили и декомпилированные исходники в пакет не входят. Английский текст обновления находится в workshop/FriendView/workshop.json. Публикация выполняется отдельным действием официального ModUploader после решения владельца.
