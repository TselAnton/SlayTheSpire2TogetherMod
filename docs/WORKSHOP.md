# Публикация Friend View 1.3.1

Исходники опубликованы в `main` и `codex/demo-1.3.1`; тег `v1.3.1` закреплён за проверенным коммитом `735a57e`. [GitHub Release 1.3.1](https://github.com/TselAnton/SlayTheSpire2TogetherMod/releases/tag/v1.3.1) опубликован 2026-10-14 в 16:32:37 UTC. Загружены архив мода, его идентичный алиас Sts2Demo, архив визуальной проверки и SHA256SUMS. Серверные SHA-256 всех четырёх файлов совпали с локальными.

После GitHub обновлён существующий [предмет Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3819332749). Официальный ModUploader вошёл как TseL и подтвердил успешную загрузку; Steam API подтвердил публичную видимость и время обновления 2026-10-14 16:34:02 UTC. Публичная история изменений содержит запись 1.3.1. ID предмета и подписки сохранены. Первая попытка из другого активного аккаунта завершилась отказом; успешная загрузка выполнена после переключения владельцем аккаунта.

Бинарные файлы и опубликованные архивы не пересобирались после проверки. Отчёты внутри архивов фиксируют состояние до публикации. Полный отчёт и ограничения — [RELEASE_1.3.1.md](RELEASE_1.3.1.md).

`scripts/Prepare-Workshop.ps1` собирает четыре файла: собственную Sts2Demo.dll, Sts2Demo.json, README.md и LICENSE. `scripts/Test-PreRelease.ps1` сверяет версии и хеши ZIP/Workshop, проверяет allowlist и запускает `universal-modder publish check`.

Игровые библиотеки, извлечённые ресурсы, тестовый мод, профили и декомпилированные исходники в пакет не входят. Английский текст обновления находится в workshop/FriendView/workshop.json. Публикация выполняется отдельным действием официального ModUploader после решения владельца.
