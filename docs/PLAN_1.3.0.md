# Friend View 1.3.0 — план и критерии приёмки

Ветка: `codex/demo-1.3.0`. База: 1.2.2. Публикация не выполняется автоматически.

1. Проверить установленную игру через universal-modder; исследовать `INetMessage`, штатную синхронизацию курсора, контексты окон и обработчики клика по игроку.
2. Передавать ограниченное состояние поддерживаемого окна при входе наблюдателя и изменениях; объединять частые изменения. Не передавать изображения. Не запускать игровые действия при восстановлении интерфейса. Неизвестные окна закрывают DEMO.
3. Включить события, магазин, гадание, костёр, выбор карт/реликвий и другие известные игровые окна. Использовать данные и ресурсы отображаемого клиентом окна, а не генерировать инвентарь повторно. Карта остаётся локальной.
4. Добавить сохраняемые настройки: вход через строку игрока (по умолчанию) / отдельный глаз; доступность бой и награды / все поддерживаемые активности. При недоступности сохранять штатный клик по игроку.
5. Уменьшить глаза, выровнять их за самой широкой полосой здоровья, перенести геймпадные подсказки вправо. Отображать верхнюю панель выбранного игрока с иконкой, без текстовой подписи DEMO (уточнение пользователя).
6. Проверить протокол, ограничения частоты, неизвестные окна, отключения, восстановление локального UI, игровые модели до/после наблюдения. В изолированной игре проверить исходное окно и DEMO для каждого сценария, включая несколько игроков и управление.
7. Собрать 1.3.0, провести аудит архива, подготовить сравнительную галерею и отчёт. Непроведённые проверки явно отделить от успешных; стабильный релиз не объявлять проверенным при открытых обязательных проверках.

Scan 2026-10-14: Steam app 2868840, Godot 4.5.1, managed .NET, античит в установке не обнаружен. Используется встроенный загрузчик и Harmony. Исследуемые декомпилированные файлы остаются вне репозитория. Тестовая копия отключает Steam и использует отдельный каталог данных.
