## Изменения

- Инициализация Harmony на Linux: системная libgcc/libunwind открывается глобально, устраняя найденную в логах недоступность `_Unwind_RaiseException`. Системные пакеты/файлы и настройки запуска не меняются. [Исходное обсуждение Godot/MonoMod](https://github.com/godotengine/godot/issues/81032).
- Обычный профиль только при единственном успешно загруженном Friend View без ошибок; любой другой мод сохраняет изоляцию. Путь фиксируется на процесс. Файлы не переносятся/объединяются, MODDED-режим не скрывается. Решение согласовано пользователем.
- Название Friend View в отображении/логах/документации. Внутренний Sts2Demo ID сохранён для обновления без второго экземпляра.
- Полный чек-лист и автоматический pre-release runner добавлены.
