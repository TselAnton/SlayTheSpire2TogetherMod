Действия берутся из штатной раскладки: `MegaInput.select` для входа/переключения (Xbox A),
`MegaInput.cancel` для выхода (B), `MegaInput.accept` для улучшений наград (Y). В бою accept
остаётся у штатного LOCAL End Turn. Подсказки клонируют контроль `%ControllerIcon` из
установленной игры и получают текстуру через `NInputManager.GetHotkeyIcon`.
Текущий `_controllerInputMap` читается без изменения; remap/type/mouse-mode отражаются в UI.
Состояние владения press/release исключает двойные действия и утечку отпускания после выхода.

Native-лаборатория отдельно проверяет физические *синтетические* controller-действия
через `Viewport.PushInput`, переназначение, смену Xbox/PlayStation glyph-стратегии и алиасы.
Это не проверка настоящего устройства, Steam Input или сетевого кооператива.
Ручной список **V121-01–12 NOT RUN**: [PRE_RELEASE_TESTS.md](PRE_RELEASE_TESTS.md).

## Изменения

- Инициализация Harmony на Linux: системная libgcc/libunwind открывается глобально, устраняя найденную в логах недоступность `_Unwind_RaiseException`. Системные пакеты/файлы и настройки запуска не меняются. [Исходное обсуждение Godot/MonoMod](https://github.com/godotengine/godot/issues/81032).
- Обычный профиль только при единственном успешно загруженном Friend View без ошибок; любой другой мод сохраняет изоляцию. Путь фиксируется на процесс. Файлы не переносятся/объединяются, MODDED-режим не скрывается. Решение согласовано пользователем.
- Название Friend View в отображении/логах/документации. Внутренний Sts2Demo ID сохранён для обновления без второго экземпляра.
- Полный чек-лист и автоматический pre-release runner добавлены.
