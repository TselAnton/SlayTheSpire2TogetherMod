# Friend View: обязательные проверки перед публикацией

Целевой кандидат: 0.1.1; игра v0.107.1 / 59260271. Этот документ — критерии выпуска, не описание для Workshop. После каждого изменения DLL результаты, зависящие от неё, нужно повторить. Лаборатория/WSL не заменяют реальные Steam-клиенты и SteamDeck.

## Правила и доказательства

- Не использовать важный незавершённый забег для тестов. Перед ручной проверкой обычного профиля создать резервную копию его данных штатным/проверенным способом; не удалять сохранения и не выключать защиту SteamOS.
- Автоматические тесты и лаборатория работают с копией игры/изолированным профилем, Steam выключен. Тест выбора профиля сравнивает пути, не открывает реальные файлы.
- Записать версию/ветку игры, версию мода, SHA-256 DLL, ОС, способ запуска Deck (native Linux/Proton), состав модов, хоста, персонажей, разрешения и дату.
- Для каждого ID ниже: `PASS`, `FAIL` или `NOT RUN`, наблюдение и подтверждение (лог/скриншоты/команда). Не отмечать `PASS` по чтению кода или отсутствию жалоб.
- Приватные логи, Steam ID, окружение и локальные настройки хранятся только в игнорируемых папках. Не коммитить и не загружать их в Workshop.
- Открытые ошибки запуска, записи профиля, сетевого протокола или изменения игровых данных блокируют выпуск. Не публиковать без явного разрешения автора.

## Профили и сохранения: отдельные блокирующие проверки

Только после backup, на отдельном тестовом профиле/копии данных. Не использовать реальный старый забег для лабораторного сценария смерти/победы.

- [ ] **S01** Friend View единственный: выбран прежний обычный профиль, видны существующие открытия/прогресс. В логах/путях нет подмены другого Steam ID или profile ID.
- [ ] **S02** Штатное сохранение и перезапуск на тестовом профиле сохраняют новый прогресс. Мод не копирует, не объединяет и не удаляет файлы.
- [ ] **S03** Friend View + любой другой включённый мод: после перезапуска используется modded-профиль; обычный остаётся защищённым.
- [ ] **S04** Обнаружение Workshop-мода во время запуска/игры не меняет каталог текущего профиля до перезапуска.
- [ ] **S05** Отключение Friend View: обычный профиль/прогресс остаются читаемыми; история и новые обычные забеги работают. Продолжение старого кооперативного забега требует корректного состава модов — проверить, не обходить предупреждения.
- [ ] **S06** Уже существующий modded-прогресс остаётся в своей папке и не перезаписывается обычным. Он не объединяется автоматически с обычным.
- [ ] **S07** На обоих устройствах правильная собственная учётная запись/профиль; Steam Cloud не создаёт конфликтов после штатного сохранения, перезапуска и отключения мода.
- [ ] **S08** При ошибке инициализации Friend View обычный профиль не выбирается. MODDED-индикация и отчётность игры не маскируются.

## Выпуск и проверка после загрузки

- [ ] **R01** Зафиксирован полный отчёт для точного SHA-256 кандидата; блокирующие тесты не имеют FAIL/NOT RUN. Автор отдельно разрешил публикацию.
- [ ] **R02** `um publish check` повторён после последних изменений; содержимое Workshop совпадает с проверенной DLL; обложка согласована.
- [ ] **R03** Загрузка обновляет существующий ID **3819332749**, app ID **2868840**; не создаётся второй объект. Английское описание — только о моде, без результатов тестов.
- [ ] **R04** После обновления закрыть игру и дождаться загрузки на обеих учётных записях; сверить SHA-256/версию скачанной DLL, загрузку и короткий бой PC ↔ Deck.
- [ ] **R05** Состав коммита проверен на секреты/локальные данные; после разрешения выполнены commit/push в текущий репозиторий без force push.
- [ ] **R06** Сохранена предыдущая собственная версия мода для отката. При регрессии откатывается пакет того же Workshop ID, не сохранения и не игровые файлы.
