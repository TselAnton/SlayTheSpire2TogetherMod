# Проверки перед выпуском Friend View 1.4.0

Цель: игра v0.107.1 / Godot 4.5.1 / .NET 9. Результаты конкретной сборки находятся в RELEASE_1.4.0.md. Старые отчёты 1.2.x являются историческими и не подтверждают эту версию.

## Автоматическая часть

Запустить scripts/Test-PreRelease.ps1: протокол/политика ввода, bootstrap/профиль, сборка, версии, переносимый ZIP, явный список файлов Workshop, universal-modder publish check и git diff --check.

В изолированной копии игры запустить scripts/Run-Lab.ps1. Для последовательного полного, стрессового и стартового прогона использовать scripts/Run-ReleaseValidation.ps1 с параметром -GameDir. Требуются завершение LAB FINISHED и отсутствие FAIL/VISUAL AUDIT FAILED. Сверить DLL лаборатории и архива по SHA-256. Сравнить все пары снимков через scripts/New-ValidationGallery.py. Проверки количества узлов не заменяют визуальное сравнение.

Для проверки именно собранного архива передать `-CandidateDll dist/Sts2Demo/Sts2Demo.dll`. Затем повторить с `-StressOnly`: 20 переходов между поддельным магазином и событием, вход/выход из DEMO и принудительная сборка мусора. Журнал стресс-теста хранится отдельно и не заменяет основной журнал и кадры. Счётчик комнат лаборатории сбрасывается между циклами, как при штатном переходе по карте: сериализатор игры отводит на него четыре бита.

## Приёмка в игре

| Проверка | Критерий |
|---|---|
| Настройки | Короткие английские/русские названия слева, галочки справа, штатные подсказки мышью/геймпадом; сохранение после перезапуска |
| Вход | По умолчанию отдельные глаза; недоступный DEMO сохраняет обычный клик; отдельные глаза выровнены и появляются группой |
| Загрузка | Задержка одного друга не скрывает его глаз; ожидание выделено, устаревшее окно не показывается |
| Бой | Чужие карты/энергия/цели правильные; завершение своего хода работает; после выхода своя рука доступна |
| Зелья | Цели враг, союзник и строка игрока совпадают; после использования зелье исчезает |
| Награды | Разные варианты у двух друзей и наблюдателя; переключение 2→3→2 не смешивает модели и владельцев |
| Активности | Магазин/покупка, события/диалог, гадание/раскрытие, костёр, реликвии вне сундука и все поддерживаемые выборы карт совпадают с источником |
| Хидер/карта | Наблюдаемый игрок и только иконка; карта и настройки локальные; колода наблюдаемая |
| Восстановление | Неизвестное окно, смена комнаты, разрыв связи, быстрые входы/выходы: нет зависших стрелок, HP-полос, анимаций или заблокированной руки |
| Нагрузка | Без наблюдателей нет подробных снимков; неизменившееся окно не повторяется; изменения не чаще 2 Гц; измерить FPS/трафик на слабом клиенте |

## Обязательные внешние проверки

Два реальных Steam-клиента, затем 3–4 участника; поменять хоста и наблюдателя. Разные разрешения и языки, физический контроллер/Steam Deck, потери пакетов/переподключение. Проверить обычный и modded-профили на тестовых слотах без перемещения сохранений. Сценарий — COOP_TEST.md.

Непроведённые пункты остаются непроведёнными. Синтетический транспорт лаборатории не подтверждает Steam P2P, производительность Deck или все ветви всех событий. При воспроизводимом падении или визуальной ошибке выпуск блокируется до исправления и повторной проверки.

## Регрессии 1.4.0

- Забрать последнюю награду: панель закрывается, остаются персонажи. Проверить включённый и выключенный авто выход по завершении комнаты.
- Менять draw/discard/exhaust у наблюдаемого игрока, переключить 2→3→2, выйти: счётчики принадлежат правильному игроку, подписки не дублируются.
- Навести на карту/диалог, прекратить поступление снимков окна: локальный переход завершается; полный снимок не пересоздаёт неизменённые узлы. Проверить прокручиваемый список.
- Проверить редкое свечение карты и другие частицы: нет чёрных прямоугольников, сохранены additive/flipbook материалы.
- Начать и закончить прицеливание при активном DEMO: нет второй чёрной траектории; после выхода штатные линии других игроков работают.
- Когда друг на карте, кликнуть его аватар: закрывается DEMO, возвращается локальный экран, колода персонажа не открывается.
- В магазине наблюдателю виден курсор, декоративная рука отсутствует.
