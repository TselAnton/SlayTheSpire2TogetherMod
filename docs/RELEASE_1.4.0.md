# Friend View 1.4.0 — локальный кандидат

Игра v0.107.1, Godot 4.5.1, .NET 9. Ветка `codex/demo-1.4.0`. Публикация и отправка в Git не выполнялись. Исходная установка игры и её сохранения не изменялись.

## Причины и исправления

| Запрос | Причина | Изменение |
|---|---|---|
| Раннее падение до логотипа | Native Sentry освобождает логгер во время обхода process_frame; копия обработчиков содержит dangling callable | Нативный shutdown перенесён через CallDeferred; подтверждено совпадающими дампами и A/B воспроизведением без Friend View |
| Аватар не закрывает выбор карт | Штатный модальный выбор отключает hitbox строки игрока | Нажатие/отпускание по аватару активного наблюдения обрабатываются до GUI; проверено настоящими событиями мыши |
| Сброс выбора карты | При открытии штатная карта заново рассчитывает отображение точек; отмена сетевого голоса не доказана | После открытия восстановлены визуальные отметки из MapSelectionSynchronizer; голос не переотправляется, не отменяется и карта не генерируется заново |
| HP, броня, статусы и Костя | Заменялась рука, но штатный HUD сохранял локальную перспективу | Штатный HUD показывается для владельца DEMO и его PetOwner независимо от класса. HP бирюзовый `#38D6C7`: обычный зелёный уже используется игрой |
| Звёзды Наследника | Отдельный классовый виджет не был подключён | Штатный NStarCounter с наблюдаемым владельцем и отдельным материалом |
| Сферы Дефекта | Слоты/сферы оставались в удалённом стиле и скрывались | Существующий NOrbManager переключает визуальную перспективу, сохраняя штатные события добавления, зарядки и вызова |
| Счётчики стопок | Нужна привязка к владельцу и корректные подписки | Повторно проверены draw/discard/exhaust, изменения количества, переключение владельца и восстановление своей колоды |
| Рука торговца | Предыдущий фильтр исключал скриптовый дочерний узел, но не Spine-изображение родителя | Декоративная рука полностью исключена из DEMO, курсор остаётся. Частота передачи не увеличена |
| Независимые стопки/колода и Esc | Утилитарные окна не имели приоритета над удалённой навигацией | Локальный просмотр сохраняет список и владение навигацией; Back/Esc закрывает его; после возврата используется актуальное состояние друга |
| Сундук | Общая проекция не обеспечивала корректный выбор реликвий | Вся комната сокровищ запрещена; активное наблюдение завершается до выхода из комнаты. Выбор реликвий в других комнатах остаётся |
| Неактивные кнопки и затемнение | Кнопки/chrome рисовались выше штатного перехода | Неактивные глаза остаются отключёнными; переход покрывает весь DEMO. Исходный Z-порядок восстанавливается при завершении забега |
| Настройки | Открытие служебного окна трактовалось как прекращение просмотра | Локальные настройки сохраняют DEMO, не перенаправляют публикацию на своё окно |
| Чужие реликвии | Невидимые оригинальные элементы продолжали принимать hover | Оригинальные элементы временно не принимают мышь; подсказки строят штатные holders наблюдаемых реликвий |
| Призма, цикада и персональные враги | Намерение использовало LocalContext; цикада рисовала только локальную украденную карту | Узкая синхронная область рендера для штатных намерений; SwipePower выбирается по владельцу. Визуальные цели Myte/SnappingJaxfruit тоже переключаются |
| Лучезарность и другие предпросмотры | Копии карт не получали выбранного врага | NCard.SetPreviewTarget получает идентификатор синхронизированной цели, штатный расчёт применяется к отдельной визуальной модели |

При полном тестировании исправлены ещё два пограничных случая: после победы/смерти визуальные слоты сфер уже очищены, хотя модель ещё хранит их количество; автоматическое следование должно переживать переход «бой → выбор карты → бой». Ручной выход останавливает автоматическое следование.

О причинах старых рывков: промежуточные позы передавались редкими снимками и пересоздавали визуальные элементы. Локальная интерполяция/hover и сохранение эффектов из 1.3.1 сохранены. Рука торговца теперь действительно скрыта на уровне родительского изображения. Повышение частоты больших сетевых снимков не использовалось.

## Новые возможности

Cross DEMO разрешён: каждый клиент публикует исходную собственную руку/нативное окно. Observer-элементы и его подсказки не входят в снимок. Открытая наблюдателем карта/утилитарное окно не заменяет исходный контекст публикации.

Пять настроек на английском/русском со штатными подсказками и галочками справа, все по умолчанию включены:

- Show Friend View Button — отдельные кнопки. Существующий явный выбор сохраняется.
- Exit When All Turns End — выход по общему завершению хода.
- Auto Watch After My Turn — переход к первому не завершившему ход, затем к следующим.
- Exit When Room Is Complete — выход по доступной кнопке «Продолжить».
- Follow Combat Interactions — следование наведению/выбору друга. Если выключено, наблюдатель независимо рассматривает и выделяет карты, не разыгрывая их.

Battle and Rewards Only удалён, старый ключ игнорируется. Протокол описания окна обновлён до 5: добавлено RoomComplete. Всем участникам нужна одинаковая 1.4.0. Подробные изменения по-прежнему ограничены 2 Гц, курсор/рука — 10 Гц, без видеопотока; неиспользуемые подробные снимки не передаются.

## Разбор раннего падения

В `artifacts/fail-logs` исходного проекта:

- `godot2026-10-15T02.01.59` / `02.01.15`: ошибка штатного debug console до создания консоли и до инициализации Friend View.
- `02.07.15`: предупреждение ObjectDB об invalid instance, после которого журнал продолжает настройку отображения. Фатальное завершение этим не доказано.
- `02.04.27`: подтверждённая ошибка старого Friend View при форматировании smartDescription силы без OnPlayer. Этот собственный путь удалён, используются штатные виджеты сил.
- Последний короткий журнал обрывается после SteamStats без фатального стека. Windows Application events за указанную дату не установили новый сбой Friend View; старые coreclr access violations относятся к предыдущим лабораторным сборкам.

Обновление 16 октября: найдены пять Crashpad-дампов в папке Sentry, в том числе соответствующий новому неудачному запуску 09:30:01. Подтверждён use-after-free native SentryGodotLogger; минимальный тест без Friend View воспроизвёл тот же стек. Исправление и доказательства: [STARTUP_CRASH_2026-10-16.md](STARTUP_CRASH_2026-10-16.md). ConfigFile не был причиной этого падения. Steam/Workshop целиком лабораторией не воспроизводится.

## Границы результата

Лаборатория запускает настоящую игру и её ресурсы с четырьмя синтетическими участниками. Она проверяет нативный рендер, сериализацию, маршрутизацию ввода и модель состояния, но не подтверждает Steam P2P между двумя компьютерами. Для большинства сравнительных пар исходное нативное окно воспроизводится как состояние отправителя 2; отдельные проверки наград/карт/врагов задают различающихся владельцев и сверяют их непосредственно.

Автоматический переход 2→3→4→выход проверяется изменением штатного набора готовности в лаборатории, включая cross presence и переходы в выбор карт. Это не запись четырёх живых участников, заканчивающих ход через Steam.

Проанализированы другие LocalContext-зависимые места: намерения покрыты общим рендером NIntent; цикада и визуальные цели имеют отдельную обработку. Это не исчерпывающий прогон каждого врага, каждой карты и всех ветвей событий. Асинхронная игровая логика не получает глобальную подмену локального игрока. Декоративные эффекты могут отличаться по фазе. Read-only список наград сохраняет отдельную непрозрачную подложку; точное совпадение его фона с исходным окном этим релизом не обеспечивается.

Не выполнены реальные Steam 2/4-клиента, физический геймпад/Steam Deck/Linux, разные разрешения и сетевые потери, длительный FPS/трафик тест на слабом ПК. Сценарий внешней проверки: COOP_TEST.md. Причина конкретного раннего краша установлена и исправлена; из-за перечисленных внешних проверок сборка сохраняет статус кандидата.
